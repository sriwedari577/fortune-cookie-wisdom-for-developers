# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written by a
small deterministic program. The line is a quiet prophecy for anyone who
has ever opened their own old code: the reader you are writing for is
already here, and it is you, later.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt`: one line, 69 bytes including its newline.
Running it twice produces byte-identical output.
